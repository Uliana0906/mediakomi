# МедиаКоми — угадай цену квартиры

Мини-игра по данным объявлений Авито о квартирах в Республике Коми.
Смотрите фотографии квартиры, передвигайте бегунок и пытайтесь угадать цену.
После 10 раундов — итоговый балл и «звёздный» архетип: **Жадный студент**,
**Адекватный квартирант** или **Мажор**.

## Возможности

- 🖼 Галерея фотографий каждого лота (свайп, точки-индикаторы, счётчик фото)
- 🎚 Бегунок оценки цены от 100 тыс. до 2 млн ₽
- 📊 Баллы за точность: ±10% — 100 б., ±20% — 75 б., ±35% — 50 б., ±50% — 25 б., дальше — 0
- 🔗 Ссылка на реальное объявление после каждого раунда
- 📈 Прогресс-бар и счёт баллов на протяжении игры
- 🏆 Итоговый архетип по характеру оценок
- 📱 Мобильная версия в приоритете (одна карточка — один экран)

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub (например, `mediakomi`).
2. Загрузите в него файлы `index.html`, `style.css`, `app.js`, `data.js`:

   ```bash
   git init
   git add .
   git commit -m "МедиаКоми: игра"
   git remote add origin https://github.com/<ВАШ_ЛОГИН>/mediakomi.git
   git push -u origin main
   ```

3. В репозитории откройте **Settings → Pages**.
4. В разделе **Build and deployment → Source** выберите
   **Deploy from a branch**, ветка **main**, папка **/(root)**, нажмите **Save**.
5. Через минуту игра будет доступна по адресу
   `https://<ВАШ_ЛОГИН>.github.io/mediakomi/`

Никакой сборки не требуется — это чистые HTML/CSS/JS.

## Обновление данных

Данные лежат в `data.js` (массив `LISTINGS`) и сгенерированы скриптом
`scripts/convert.py` из CSV-выгрузки объявлений. Чтобы обновить лоты,
поправьте путь `SRC` в скрипте под новую выгрузку и запустите:

```bash
python -X utf8 scripts/convert.py
```

Скрипт отбирает только объявления, у которых есть хотя бы одно фото.
